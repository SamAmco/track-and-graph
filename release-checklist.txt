- Run `make validate-all` or `make validate-remote-config` and `make run-community-tests`

- Update the build.gradle version code and name

(also make sure you update any other fastlane resources you want proliferated e.g. screenshots or app description.)

- Run `make changelog` to generate a changelog from merged commits since the last release

- Run `make commit-version` to commit the version bump and changelog (before release to ensure reproducible builds)

- Run `make assemble-bundle-release` to generate the Play Store release APK/AAB

- Run the Play Store release build on a device to sanity check it:

adb install app/app/build/outputs/apk/playStore/release/app-playStore-release.apk

- Use fastlane to upload the new aab to the play store e.g. for alpha:

bundle exec fastlane supply --aab app/app/build/outputs/bundle/playStoreRelease/app-playStore-release.aab --track alpha

for beta:

bundle exec fastlane supply --aab app/app/build/outputs/bundle/playStoreRelease/app-playStore-release.aab --track beta

or for release:

bundle exec fastlane supply --aab app/app/build/outputs/bundle/playStoreRelease/app-playStore-release.aab --rollout 0.5

- Run `make assemble-foss-release` to generate the F-Droid/GitHub release APK

- Optionally sanity check the F-Droid/GitHub release build:

adb install app/app/build/outputs/apk/foss/release/app-foss-release.apk

- run `make github-release` to create a new github release with the changelog and apk attached
