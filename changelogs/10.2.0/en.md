## App Lock! 🔒

**Version 10.2.0** introduces App Lock. You can now set a lock screen on Track & Graph to keep your data private when someone else has access to your device.

---

## Reminder Controls! ⏰

Reminders can now be enabled or disabled without deleting them.

---

## Bug Fixes and Improvements

- Added haptic feedback when adding a data point
- Bar charts now use the vico library for better zooming/highlighting interactions
- Notes and data points now animate smoothly when rows are added or removed
- Fixed bug: fuzzy search could crash when matching some Unicode text
- Data point and note search can now match dates and times
- Improved spacing in the add data point dialog
