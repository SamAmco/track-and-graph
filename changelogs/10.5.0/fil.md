## Mas Maraming Wika! 🌍

Nag-aalok na ngayon ang Track & Graph ng 67 pagpipiliang wika!

Gumamit ako ng AI para isalin ang app, kaya pakibantayan ang mga maling salin. Kung gusto mong tumulong, mangyaring gumawa ng isyu sa GitHub para sa anumang mukhang mali sa gusto mong wika 🙏

Sa Android 13 at mas bago, maaari mo ring piliin ang **Wika ng app** mula sa navigation drawer upang itakda ang wika ng Track & Graph nang hiwalay sa wika ng iyong telepono.

---

## Mas Malinaw na mga Graph! 📊

Ginagamit na ngayon ng lahat ng graph ang custom na canvas code. (R.I.P. AndroidPlot at Vico. Maraming salamat sa inyong mga serbisyo 🙏)

Itinuturo na ngayon ng mga label sa X-axis ang mismong mga data point at mas maayos at madaling basahin ang pag-format ng petsa/oras. Nakadikit din ang mga label sa data at nahahati sa mas maliliit na pagitan kapag nag-pan at nag-zoom ka sa full-screen mode.

## Mga Isang Beses na Paalala! ⏰

Maaari ka na ngayong gumawa ng **Isang Beses** na paalala nang hindi ito iniuugnay sa isang tracker o function. Pumili ng partikular na petsa at oras, o ng pagkaantala gaya ng “pagkalipas ng dalawang oras”. Maaari ka ring magtakda ng pagitan ng pag-uulit para sa mga kasunod na notification pagkatapos ng unang paalala.

May bagong opsyon din ang mga paalalang **Oras Mula sa Huli**: maaari kang pumili ng partikular na oras ng araw para sa notification. Halimbawa, paalalahanan ang iyong sarili nang 9 ng umaga dalawang araw pagkatapos ng huli mong entry.

## Mga Pag-aayos ng Bug at Pagpapahusay

- Pinahusay ang keyboard focus at mga animation sa pagbabago ng laki ng dialog kapag lumilipat sa pagitan ng mga tracker habang nagdaragdag ng mga data point.
- Pinahusay ang pagpapanumbalik ng backup, kabilang ang pagsusuri sa mga sira o hindi tugmang backup file bago palitan ang iyong data.
- Hinihingi na ngayon ng pag-export ng CSV kung saan ise-save ang file pagkatapos mong piliin kung ano ang ie-export, kaya naiiwasan ang mga walang laman na file kapag nagkansela ka bago mag-export.
- Inayos ang isang bug kung saan minsan ay hindi muling bumubukas ang dialog ng pag-import/pag-export pagkatapos itong isara.
